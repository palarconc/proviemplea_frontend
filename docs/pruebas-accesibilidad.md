# Pruebas de accesibilidad y usabilidad

## Objetivo

Verificar que la landing page de ProviEmplea sea clara, navegable, comprensible y usable para distintos tipos de usuarios.

## Pruebas realizadas

| Prueba | Resultado |
|---|---|
| Navegación por menú superior | Correcta |
| Enlaces internos a secciones | Correcta |
| Botón "Ver talentos disponibles" | Correcto |
| Botones "Contáctanos" | Correctos |
| Formulario con etiquetas visibles | Correcto |
| Validación de campos obligatorios | Correcta |
| Mensajes de error visibles | Correctos |
| Diseño adaptable a escritorio | Correcto |
| Diseño adaptable a móvil | Correcto |
| Uso de `aria-label` en menú móvil | Correcto |

## Mejoras aplicadas

- Se agregaron etiquetas `label` en el formulario.
- Se incorporaron mensajes de error claros.
- Se utilizó navegación por secciones.
- Se aplicó diseño responsive con Bootstrap.
- Se agregó estructura visual clara en tarjetas, estadísticas y formulario.

## Conclusión

La interfaz permite navegar de manera clara por las secciones principales, visualizar información dinámica desde la API y completar el formulario de contacto con validaciones básicas.
